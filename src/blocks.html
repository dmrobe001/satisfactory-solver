What a block is

A factory here is a whole number of machines per recipe, every machine at 100 %. It is valid when every fluid and every unusable item nets exactly 0, every usable item (anything the build gun uses, ammunition, filters, fuels, power shards) nets 0 or more, and every raw resource is only drawn, in whole multiples of 30 per minute. Valid factories add up to valid factories. A block is a valid factory that cannot be split into two smaller valid factories. Because machine counts cannot be negative, the set of blocks is finite and unique, and every valid factory of the pool's recipes is a sum of blocks (often in more than one way). Computed exactly with Normaliz (tools/blocks.py).

Elementary modes (marked “mode”) are the blocks that are also extreme rays of the cone: with these standard recipes, one per usable product, the smallest whole-machine chain that makes only that product. The other blocks mix several products whose fractional machines complement each other: for example two steel foundries can feed one beam and one pipe constructor exactly, though neither product alone balances with so few machines.

Restricting the recipes never changes a block, it only removes blocks: the iron–copper–limestone library is exactly the part of the coal library that uses no coal. Pools: standard recipes only (no hard-drive alternates), reachable from the listed raw resources without hand-gathered items.
